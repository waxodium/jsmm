# Agentic Engineering and Automated Tools
This document outlines the rules, requirements, 
and guidelines for agents and automated tooling within the JS-- (JSMM) JavaScript Engine source code and project.

The JS-- project **restricts and disallows** AI code-writing and interaction for new contributors entirely.

For new contributors using agentic engineering, 
agents must be granted **READ-ONLY** permissions for this project and its source code.

## Prohibited Contributions
- **No usage of Git commands**: Agentic interaction with the JS-- project **must never** involve Git. 
It is strictly prohibited for agents to execute any Git commands to manage the repository, even with human review. 
Git changes and decisions must be handled by humans, 
who must confirm that the code changes were written and verified accordingly.

- **No commenting on code**: Agents are prohibited from adding comments to the code. 
This is a violation of code standards and may result in 
unmaintainable source code for human reviewers and maintainers. 

- **Automated PRs**: A pull request into the official Git repository on any branch of JS-- forbids automated writings. 
Pull requests must be explicitly hand-written, even if your English is not decent. 
But is not restricted to Artificial Intelligence usage for grammar fixes and reviewing.

- **No changes to documentations**: Documenting the project is a maintainer responsibility. Agents must not interfere
this work ever.
