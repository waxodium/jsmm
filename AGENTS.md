# Agentic Engineering and Automated Tools
This document outlines the rules, requirements, and guidelines for agents and automated tooling within the RMA JavaScript Engine source code and project.

The RMA project **restricts and disallows** AI code-writing and interaction for new contributors entirely.

For new contributors using agentic engineering, agents must be granted **READ-ONLY** permissions for this project and its source code.

## Prohibited Contributions
- **No usage of Git commands**: Agentic interaction with the RMA project **must never** involve Git. It is strictly prohibited for agents to execute any Git commands to manage the repository, even with human review. Git changes and decisions must be handled by humans, who must confirm that the code changes were written and verified accordingly.

- **No commenting on code**: Agents are prohibited from adding comments to the code. This is a violation of code standards and may result in unmaintainable source code for human reviewers and maintainers.
